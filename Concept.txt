1. Class and Object
A class is a blueprint, while an object is an instance of that class.

2. Encapsulation
Encapsulation means hiding internal data and controlling access to it.

3. Inheritance
Inheritance allows one class to reuse properties and methods of another class.

4. Polymorphism
Polymorphism means one interface/name can have different behaviors.

Concept	Meaning
Encapsulation	Hide/protect data
Inheritance	Reuse code from another class
Polymorphism	Same method/interface, different behavior
Abstraction	Hide implementation details
